Overview

Web Service Antrean BPJS Mobile JKN FKTL

Dokumentasi resmi Web Service Antrean BPJS Mobile JKN FKTL untuk RSUD Merauke, tahun 2026. Gunakan endpoint Mengambil Token terlebih dahulu untuk memperoleh x-token, lalu sertakan token tersebut pada header setiap permintaan berikutnya bersama x-username.

BASE https://mjkn.rsud-merauke.id

Format Respons

Setiap respons sukses memuat objek metadata dengan code: 200 dan message: "Ok". Pilih salah satu endpoint pada panel kiri untuk melihat detail permintaan dan contoh respons.

Endpoint 01 / 11

Mengambil Token

GET /auth

Mengambil token autentikasi yang digunakan pada seluruh endpoint lain. Sertakan token ini pada header x-token di setiap permintaan berikutnya.

Request

Header Parameters

x-usernamestring
User yang diberikan pihak rumah sakit.
x-passwordstring
Password yang diberikan pihak rumah sakit.

Responses

200default
tokenstring
Token autentikasi, berlaku untuk sesi berjalan.
